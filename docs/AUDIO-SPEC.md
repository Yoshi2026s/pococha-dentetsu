# ポコチャ電鉄 音響仕様書（第34版）

2026年10月27日（日本時間）／対象：index.html の「第34版 音響エンジン」区画

## 方針

- すべての音はブラウザ内でその場に合成する（音源ファイル・外部ライブラリなし）。曲・効果音はすべてオリジナル。
- 音はゲーム計算・抽選・同期に関与しない。通信処理・Firestoreルール・RULES_VERSION（32）は変更なし。
- スマホのスピーカーで聞こえることを優先（低音は同じ高さのサイン波＋倍音つきの波形で鳴らす）。

## 音の通り道

| 区分 | 内容 |
|---|---|
| 曲バス | 音量 → 低域+2.5dB（120Hz）→ こもり−2dB（420Hz）→ 高域+1.5dB（9kHz）→ ダッキング → 出口 |
| 効果音バス | 音量 → 45Hz以下カット → 2.8kHz+1.5dB → 出口 |
| 出口 | グルー圧縮（−18dB・3:1）→ リミッター（−2.5dB・20:1）→ スピーカー。音割れを防ぐ |
| 残響 | ホール2.6秒（初期反射9本＋だんだん暗くなる残響尾、左右別）。190Hz以下・7.5kHz以上を削って濁りを防ぐ |
| こだま | 左右に跳ねるピンポンディレイ。間隔は曲のテンポの付点8分に自動で合わせる |

## 音量

- 設定の音量：BGM＝設定値×0.30、効果音＝設定値×0.36（出口の圧縮・リミッター込みで旧版より約6dB大きく、上限は音割れしない）。
- 曲ごとの音量合わせ：`SONG_GAIN` で全13曲の平均音量を約−29dBにそろえる（test-audio.cjsで測定した係数）。
- ダッキング：効果音が鳴る間、曲を一時的に下げる（例：サイコロ60%・0.5秒、ランクアップ40%・1.6秒）。ゴール・レア演出は従来どおり大きく下げる。長い演出中に短い効果音が鳴っても、長い方の指定を上書きしない。

### 演奏の強化点

- メロディは次の休みまで音を伸ばす（レガート）。長い音には遅れてかかるビブラート。
- 拍頭を少し強く、音ごとに±7%の強弱のゆらぎ（人が弾いたような表情）。
- B部分と2回目以降のA部分では、コードの音から3〜6度下のハモリを自動で重ねる（豪華・ふつう時のみ）。
- ベース：やわらかいノコギリ波（フィルターが閉じていく）＋同じ高さのサイン波。
- パッド：ストリングス風（ゆっくり立ち上がり、次の小節へつながる）。控えめではサイン波。
- ドラム：キック（ピッチ下降＋アタック音）、スネア（胴鳴り＋響き線）、クラップ、リム、オープンハイハット、タム、シンバル、和太鼓、鉦（かね）、シェイカー、ティンパニを新規合成。
- 部分の切り替わりでシンバル、部分の終わりでタムのフィルイン。
- 新しい音色：パルス波（ファミコン風）、オルガン、やわらかいノコギリ波、三線、マリンバ。
- 2026年10月31日の追加（POP曲・場面の曲で使用）：
  - 部分ごとの盛り上がり（前奏は軽め、サビは手拍子・オープンハイハット・きらめきの高音を足す）。サビの前に盛り上げの音（ノイズが上がっていく）。
  - 裏拍の和音の刻み（off＝裏拍、push＝3・3・2のノリ）、対旋律（ベル・マリンバ）、16分のハイハット。
  - 最後のサビで全音上げる転調（いつもの曲）。
  - 新しいリズム：dance（4つ打ち）、chase（追いかけ）。新しいベース：oct（オクターブで弾む）。

dice（転がる→着地→確定チャイム）、step（線路の継ぎ目「タタン」＋進んだ数で上がる音）、station（到着チャイム＋ブレーキの空気音）、buy（コイン＋レジ）、yell、anti、card、troll、myturn、stamp、rankup、clock、roulTick、roulStop、firework（打ち上げ笛→ドーン→パチパチ）、rarN〜rarUR、badSR、badUR、goal、goalBig、goalOld、ui（ボタンを押した小さな音・新規）。

## 設定（音と設定）

- BGM・効果音の音量（従来どおり）
- 「ボタンを押した音」（新規・初期オン。保存キー `ui`）
- 「曲を試聴」（新規）：13曲から選んで試聴。とじるとゲームの曲に戻る。
- 「演出の量」：控えめでは残響・ハモリ・パッドの倍音・拍手の数を減らし、同時発音の上限を70に下げる（ふつう120・豪華170）。

## 処理落ち対策

- 同時発音数は「鳴り終わる予定時刻」で数える（onendedに頼らないため、曲の切替や切断で数がずれない）。上限を超えたら曲の飾り（パッド・アルペジオ・ハモリ）を省く。効果音は省かない。
- 画面を離れたら音を一時停止し、戻ったら再開（裏で途切れ途切れに鳴るのを防ぐ）。iPhoneで再開しないときは画面をタップすると鳴る。
- iPhoneのマナーモード対策（無音の音声を流す）は従来どおり。

## テスト

- `node test-audio.cjs [WAV書き出し先]`：全13曲・全26効果音をOfflineAudioContextで書き出し、非数値・無音・音割れ・平均音量・ノード生成数を検査。結果 `audio-test-results.json`。
- `node test-audio-live.cjs [秒数]`：本物のAudioContextで端末内モードの対戦を自動操作＋全曲・全効果音の連続切替。例外・同時発音数・停止後の残りを検査。結果 `audio-live-results.json`。
- どちらもPlaywright（Chromium）が必要。実機スピーカーでの聞こえ方・音量感は対象外。
